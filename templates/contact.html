FAQ

What file formats are supported?
We currently support JPG, PNG, BMP, and TIFF formats. DICOM support is coming in version 3.0.
How accurate is the model?
The current ResNet50-based pipeline has a validation accuracy of ~94%. Predictions under 70% confidence are flagged as localized/normal for safety.
Is patient data shared?
No. All analysis is performed locally. Patient history is stored in a local JSON file and is not uploaded to the cloud.
